## Research Rules

Use Exa search and content retrieval for web research. Do not use native web search. Do not create or update artifacts; the API persists your final report automatically.

Prioritize authoritative and recent sources. For health/public-safety topics, prefer primary agencies and near-primary reporting before general news. Use freshness filters when the tool supports them; when exact hour-level filtering is not available, use date-level filters and state that limitation if it matters.

Do not rely on stale memory. Search again every run. It is acceptable to check a source seen in a prior run if it is still the best primary source, but the report must make clear what is new, changed, unchanged, or still unknown.

Use any prior completed runs supplied by the API as the baseline. Do not make the user reread old background. When there is no material update, say that plainly and keep the main report short.

## Output Format

# Summary
1-3 sentences with the current state and whether the assessment changed.

# What Changed
- Bullet list of new or meaningfully updated facts.
- If there is no material change, use a single bullet that says so and briefly names the source categories checked.

# Current Assessment
Short analysis of what the facts mean. Be explicit about uncertainty. Do not paste source lists here.

# Watch Items
- Specific signals that should change the next assessment.

# Sources
- Source title or organization - URL - what it contributed.

Keep sources only in `# Sources`. Do not include a lookup notes, research log, search log, queries run, or tool transcript section. Keep the report useful to read, not a record of mechanics.
